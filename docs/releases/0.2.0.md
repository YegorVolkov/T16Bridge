# T16Bridge 0.2.0

## Sensitivity profiles

- Save multiple named profiles containing curves and freeze-button assignments
  for both sticks and all eight axes.
- Create a linear setup with New, copy the current setup with Duplicate, and
  rename it. Copies are independent and can be adjusted without changing the original.
- Switch profiles without restarting the bridge. Edits and the selected profile
  are saved automatically in profiles.json.
- Import existing curves.json settings into Default, keeping the original file intact.

## Axis freeze controls

- Select LEFT or RIGHT and an axis, then use Detect Freeze/Unfreeze X axis
  (or Y, Rz, Slider) to assign a physical button on that stick.
- Use Detect Freeze/Unfreeze all axes to assign another button that toggles all
  four axes of the selected stick. LEFT and RIGHT have independent assignments
  and hold states, saved with the sensitivity profile.
- A press captures the current output after applying the sensitivity curve;
  another press releases it to the current physical position. A held button
  does not toggle repeatedly. Partially frozen sticks keep their held values
  when the remaining axes are frozen together.
- Changing profile, changing an assignment, or restarting clears runtime holds.
  The application never restores held positions from disk.
- Detection ignores already-held and ambiguous simultaneous presses, and cancels
  when the selected device, axis, or profile changes. Inputs still reach games.
  Unlocking may jump to the current physical position.

## Live controller panel

- Display a contoured T.16000M diagram with shaped grip buttons and base button banks.
- Follow the selected device and axis automatically: LEFT uses the left-handed
  diagram and RIGHT uses the right-handed diagram. Match the physical base switches.
- Show assigned buttons in blue, physical presses in orange, and the selected
  axis's frozen/free status beside the curve preview.
- Keep the panel frameless, with two detection buttons directly below the diagram
  legend. Assign buttons through physical detection, without manual selectors.

## Shared driver compatibility

- Upgrade HIDMaestro from 1.9.0 to 2.1.0.
- Preserve controllers owned by running HIDMaestro applications during uninstall.
  Keep the shared HIDMaestro driver and HidHide installed, leave HidHide's global
  hiding state unchanged, and remove T16Bridge's device rules and settings.
- Retain bundled third-party license files.

## Upgrading from 0.1.0

Close T16Bridge and install 0.2.0 over the existing installation. Do not run the
old uninstaller first: it removes shared components. Start and close the updated
T16Bridge once to reclaim and dispose its legacy controller identities. Other
applications using HIDMaestro 1.x must also migrate for safe coexistence.

## Validation

Automated checks cover profile import, independent copies, naming, persistence,
physical button detection, individual/all-axes freeze toggles, binding conflicts,
and both controller diagrams. Offscreen UI checks exercise detection and output
holding through the production input-processing path. The self-contained Windows
build and installer are checked separately.

Real joystick operation, coexistence with another running HIDMaestro application,
upgrade/uninstall on a test machine, and increased display scaling still need
manual validation.
